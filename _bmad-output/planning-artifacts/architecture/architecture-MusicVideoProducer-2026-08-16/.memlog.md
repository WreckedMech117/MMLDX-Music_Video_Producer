- (decision) AD transport (FR-7/8, NFR-1): client polls the app's own API on a 2s interval while a batch is active; backend batch-reconciliation endpoint fetches ComfyUI /queue ONCE per tick and /history only for non-terminal jobs absent from queue. No ComfyUI WebSocket, no SSE. Binds Epic 4. Prevents dual sources of truth and per-job /queue fan-out (40 jobs = 40 queue calls today).
- (direction) Transport rationale: shot granularity is 288-438s; 2s polling latency is 100x finer than the event rate. Restart reconciliation must read /queue+/history regardless, so polling is the only mechanism that must exist either way; a /ws subscription would be a second mechanism layered on top with reconnect machinery in a dependency-free ES-module frontend. Sole local user makes poll load trivial. Fallback/upgrade: /ws may later WAKE the same reconciler early, never replace it as source of truth.
